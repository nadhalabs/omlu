
# Security Policy

Security is important to OMLU and Nadha Labs.

This document explains which versions are supported and how security vulnerabilities should be reported.

## Supported Versions

OMLU is continuously maintained and deployed.

Security fixes are provided for the **current production version** only.

| Version | Supported |
| ------- | --------- |
| Current production release | ✅ |
| Previous / unsupported deployments | ❌ |

## Reporting a Vulnerability

If you believe you have discovered a security vulnerability in OMLU, **please do not create a public GitHub issue or disclose the vulnerability publicly**.

Report security concerns privately to:

**kailasanadhg@gmail.com**

Please include as much relevant information as possible, such as:

- A clear description of the vulnerability
- The affected feature, page, API endpoint, or component
- Steps required to reproduce the issue
- The potential security impact
- Relevant screenshots, logs, or proof-of-concept details
- Any suggested remediation, if available

## What to Expect

Valid security reports will be reviewed as soon as reasonably possible.

Depending on the severity and complexity of the issue, we may:

- Request additional information
- Confirm whether the issue can be reproduced
- Develop and deploy a security fix
- Notify the reporter once the issue has been resolved

Not every report will necessarily qualify as a security vulnerability. Reports that cannot be reproduced or do not present a meaningful security impact may be closed without further action.

## Responsible Disclosure

When investigating or reporting a vulnerability, please:

- Avoid accessing data belonging to other users or organizations
- Avoid modifying, deleting, or corrupting data
- Avoid disrupting production services
- Avoid automated testing that may significantly affect service availability
- Do not use discovered vulnerabilities for unauthorized access or personal gain
- Allow reasonable time for remediation before any public disclosure

## Scope

This policy applies to OMLU software and services maintained by Nadha Labs.

Third-party services, libraries, hosting providers, and external platforms may be governed by their own security policies.

## No Bug Bounty Commitment

Nadha Labs does not currently operate a formal bug bounty program.

Submission of a vulnerability report does not create an obligation to provide payment, compensation, rewards, or recognition.
